NEXO PUBLICADOR

Política de privacidad

Versión 1 · 12 de noviembre de 2026

Responsable y alcance

NEXO Publicador es una aplicación de escritorio que usa únicamente el propietario del canal de YouTube NEXO — Sin Humo, que es también su operador. No ofrece cuentas ni acceso a otras personas. Contacto: contacto.nexosinhumo@gmail.com.

Servicios de API de YouTube

La aplicación usa los servicios de API de YouTube: YouTube Data API v3 y YouTube Analytics API. Al usarla, el operador acepta los Términos del Servicio de YouTube. Los datos se tratan además según la Política de Privacidad de Google. El acceso se puede revocar en cualquier momento desde la configuración de seguridad de la Cuenta de Google.

Permisos que solicita

Hay dos autorizaciones OAuth separadas, que se piden en la página oficial de Google. La aplicación nunca ve ni guarda la contraseña de Google.

Publicar: youtube.upload, para subir videos que el operador aprobó, y youtube.readonly, para confirmar antes de cada subida que la cuenta es la del canal aprobado.

Analítica: yt-analytics.readonly y youtube.readonly, para consultar el rendimiento de los videos propios del canal, solo en modo de lectura.

Qué datos se obtienen y se guardan

La aplicación obtiene y guarda solo lo siguiente:

Del canal: su identificador y su nombre, para comprobar que la cuenta autorizada es la correcta.

De cada video subido: el identificador que devuelve YouTube y el estado de la subida. El título, la descripción y la visibilidad los escribe el operador.

De rendimiento de los videos propios: reproducciones, tiempo de visualización, retención, suscriptores obtenidos y métricas similares.

Tokens de acceso OAuth: se guardan cifrados con DPAPI de Windows, vinculados al usuario de Windows del operador.

Todo queda solo en el equipo del operador. La aplicación no tiene servidor propio.

Para qué se usan

Los datos se usan solo para tres cosas: verificar el canal, subir videos expresamente aprobados y analizar el rendimiento del propio canal.

No se venden ni se comparten con terceros. No se usan para publicidad ni para crear perfiles. Se procesan localmente con el código de la aplicación y no se envían a servicios de inteligencia artificial ni a otros servicios externos. Solo se intercambian con Google y YouTube a través de sus API.

Conservación y eliminación

Los datos de las API se conservan mientras la autorización del operador siga vigente. El operador comprueba que la autorización siga activa al menos cada 30 días.

Si la autorización se revoca o deja de ser válida, los datos obtenidos de las API se eliminan del equipo dentro de los 7 días siguientes. Para eso la aplicación tiene una orden específica de borrado, y otra de desconexión que revoca el acceso en Google y elimina los tokens.

Para pedir la eliminación de datos se puede usar el contacto indicado arriba. Borrar los datos locales no borra videos ni información guardada en YouTube: eso se administra desde YouTube Studio.

Seguridad

Los tokens están cifrados y la aplicación no los imprime ni los registra. Las acciones que usan la cuenta, como conectar, aprobar o subir, las ejecuta el operador. La aplicación solo sube contenido cuya versión, metadatos y visibilidad aprobó el operador.

Este sitio web

Es un sitio estático, sin formularios, publicidad, scripts de seguimiento ni cookies propias. Lo aloja GitHub Pages, que puede registrar direcciones IP por razones de seguridad. Más información en la declaración de privacidad de GitHub.

Políticas aplicables

El uso de los datos cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado, y las Políticas para desarrolladores de YouTube API Services.

Cambios

Si cambian los usos, los destinatarios o los tipos de datos, se actualiza esta política con una nueva fecha y se vuelve a pedir la autorización cuando corresponda.
